# Estrategia Digital - Francisco Inmobiliaria

## About (Acerca de este Proyecto)
Este repositorio contiene toda la estrategia digital, propuesta comercial y el portal interactivo para el cliente **Francisco** (Asesor Inmobiliario de Constructora Fundamenta). 

El objetivo principal de este proyecto es **potenciar la marca personal** del agente, posicionándolo como un experto confiable en el mercado inmobiliario chileno. A través de contenido educativo en Instagram y LinkedIn, buscamos derribar los miedos de los compradores (créditos hipotecarios, pie en cuotas, compra en blanco/verde) y atraer *leads* (clientes potenciales) calificados.

## 📂 Estructura del Repositorio

- **`/` (Raíz):** Contiene los archivos `index.html`, `style.css` y `script.js` que conforman la aplicación web (Single Page Application) del portal del cliente.
- **`/Entregables`:** Documentos en formato Markdown (`.md`) que se muestran en el portal (Propuesta Comercial, Guía Visual, Estrategia, Guiones).
- **`/Operaciones_Internas`:** Manuales de uso interno para el equipo de producción. Detalla el cronograma de grabación en terreno y el uso de IA para automatizar la edición.
- **`chat-export-limpio.md`:** Resumen limpio de la investigación y bases del proyecto.

## ⚙️ Modelo de Trabajo (El Servicio)
Este proyecto no solo es una entrega para un cliente, sino un **producto empaquetado** que sirve de plantilla para futuros agentes inmobiliarios.
1. **Setup Inicial (1 UF):** Definición de pilares, guiones y guía de diseño.
2. **Visita en Terreno (1 UF por visita):** Sesión presencial mensual de 1 mañana (4 horas) grabando contenido en "Batching" y capturando B-Roll.
3. **Edición Automatizada:** Uso de herramientas de Inteligencia Artificial para recortar, subtitular y programar el contenido extraído de la sesión de grabación.
